```python
class MenuItem:
    """각 메뉴 아이템들을 모델링합니다."""
    def __init__(self, name, water, milk, coffee, cost):
        self.name = name
        self.cost = cost
        self.ingredients = {
            "water": water,
            "milk": milk,
            "coffee": coffee,
        }


class Menu:
    """음료 메뉴를 모델링합니다."""
    def __init__(self):
        self.menu = [
            MenuItem(name="latte", water=200, milk=150, coffee=24, cost=2.5),
            MenuItem(name="espresso", water=50, milk=0, coffee=18, cost=1.5),
            MenuItem(name="cappuccino", water=250, milk=50, coffee=24, cost=3),
            # MenuItem(name="카라멜마키아토", water=200, milk=60, coffee=26, cost=4),
        ]
```
이 부분을 확인하셔야 합니다. Menu 클래스의 생성자 부분을 확인하시면 속성(attribute)에 menu가 있습니다. 그리고 그 menu는 전체 자료형이 _list_ 이고, 내부에 MenuItem 객체가 자동으로 생성되게끔 되어있습니다.

- main.py에서 Menu() 생성자를 호출하여 객체를 생성하게 되면 자동으로 MenuItem() 객체가 3 개 만들어진다는 것을 의미합니다.
- menu.menu 내부를 보시면 MenuItem() 객체 내부에 keyword argument 방식으로 객체를 생성했음을 확인할 수 있습니다.
대표적인 예시
```python
print('안녕하세요', end='❤️')
```
- 각각의 MenuItem() 객체에 대해서 객체명은 존재하지 않습니다. 하지만 특정한 객체를 가리킨다고 알 수 있는 방법이 있습니다. -> menu.menu의 자료형이 list란 점 때문에. -> menu.menu[0]~menu.menu[2]까지 존재하겠네요.

- 이상까지의 수업에서 여러분이 커피 관련 메뉴를 추가하고 싶다면, menu.menu 속성에 MenuItem() 객체를 추가하는 방법으로 할 수 있을겁니다. -> 프라푸치노의 가격을 5.5 / 물은 140 / 커피 20 / 우유 40 잡아먹는다고 하면 객체 생성을 어디에 어떻게 해야할지 아셔야합니다.

- 현재까지의 내용은 off / report라고 입력했을 때 작동하는 부분이 작성되었고, else 파트에서 menu.menu를 반복문 돌렸을 때 item.name이 일치하면 그 객체가 빠져나오도록 find_drink()가 작성되어있습니다. 그러면서 틀리면 None이 return되도록 하는 부분까지 학습했습니다.

# 상속(inheritance)
- 부모와 자식 관계가 존재함
- 자식은 부모의 속성 및 메서드를 마음대로 사용 가능
- 부모는 불가능
  - 이상의 코드 라인에서 주의할 점은 자식 클래스에 아예 정의되지 않은 속성이나 메서드를 활용하게 될 수도 있다는 점입니다.
  - 여태까지는 class 클래스명: 내부에 딸려있는 속성 및 메서드만 확인하면 됐었습니다(coffee_machine에서 봤듯이). 하지만 복잡한 클래스들의 정의에서 상속 관계가 있다면 상위 부모에 대해서 확인할 필요가 있습니다.
   - 근데 그 클래스가 아예 다른 .py 파일에 존재할 수도 있겠네요. from import를 통해서요.
