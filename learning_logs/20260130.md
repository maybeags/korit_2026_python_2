그래서 복습 단계에서 저희가 했던 multiply(n)이라는 함수를 정의한다고 가정하겠습니다.
```python
def multiply(n):
    for i in range(1, 10):
        print(f'{n} x {i} = {n*i}')

dan = int(input('몇 단의 구구단을 출력할까요? >>> '))
multiply(dan)
```
이상의 코드가 있다고 가정했을 때 저희가 고려해야 할 점은
dan = int(input('몇 단의 구구단을 출력할까요? >>> '))에서 3을 입력했다면 dan = 3이라고 받아들였을겁니다.
multiply(dan)이라고 입력했다면 
`def multiply(n):` 이라는 지점으로 들어갔을 때 n = dan이라고 받아들일 수 있습니다.

